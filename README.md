# Sysinfo для LinCtrl Desktop

Скопируйте содержимое каталога `plugin` в `plugins/sysinfo.linctrl` рядом с LinCtrl Desktop. Включите плагин в разделе «Плагины» и войдите на сервер с API-плагином Sysinfo.

На странице показаны ОС, архитектура, время работы, процессор, доступная ОЗУ, локальные диски и обнаруженные видеопроцессоры. Заполненная часть полосы показывает занятое место, остальная часть — свободное. Задержка измеряется от отправки HTTP-запроса к выбранному серверу до получения ответа.

Иконки взяты из Bootstrap Icons. Условия лицензии находятся в `plugin/icons/LICENSE-bootstrap-icons.txt`.
